Power is a bipartite matching

From today’s session: the core’s reach in gold, with a line to each tower it powers.

Capacity and radius: core 4 towers within 4 tiles; collector 2 within 3; pylon 2 within 3.

Towers on one side, source slots on the other. Augmenting paths give as many powered towers as possible.

bool Augment(int t, ...) {
  for (int k = 0; k < slots; k++) {
    if (slotSeen[k]) continue;
    if (!InReach(k, t)) continue;
    slotSeen[k] = true;
    if (slotTower[k] < 0
      || Augment(slotTower[k], ...)) {
      slotTower[k] = t;
      return true;
    }
  }
  return false;
}

Player ties are placed first and stay fixed. Recomputed after commands and breaches: 0.007 ms.
