The primary metric, as the code computes it

H = −Σ p(r) ln p(r) / ln K

Shannon (1948) entropy of built tiles over a 6 × 6 partition. p(r) is region r’s share; K is the number of regions with a buildable tile. 0: one region. 1: an even spread.

Counted (PlacementEntropy.Counts): walls, towers, tower moves (destination only), upgrades, collectors. A tile later sold or destroyed still counts.

Not counted: sales, the core, anything before wave 1, when no wave has been seen.

Compared: each player’s two sessions, cut to the shorter one’s completed waves. Computed afterwards from telemetry with DetMath.Log, so nothing in the game reads it.

The 77-wave tester session: 555 tiles, H = 0.62 (K = 36).
