The planner seam: one interface, failure contained

Read-only by check: the state is hashed before and after every PlanWave. Any change throws.

Bad plan: wrong wave, unknown entry, HP or speed not positive. An enemy that cannot move would never let a wave end.

public interface IWavePlanner {
  string Name { get; } // saved in replay and telemetry as the condition
  WavePlan PlanWave(WaveContext context); // may only read context.State
  void OnWaveResolved(WaveOutcome outcome); // receives a copy
}
