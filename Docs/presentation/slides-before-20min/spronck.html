Dynamic Scripting (Spronck et al., 2006)

Nearest neighbour. Each agent class has a rulebase of hand-written rules, each with a weight.

Before a fight: rules are drawn into a script, with probability linear in weight.

After a fight: rules that ran gain or lose weight by fitness; all others shift so that the total stays constant.

F < b: ΔW = −Pmax × (b − F) / b
F ≥ b: ΔW = +Rmax × (F − b) / (1 − b)
b = 0.3, Pmax = 70, Rmax = 100, Winit = 100

Results: ahead of static tactics after 13 to 53 fights on average. Top culling in Neverwinter Nights: 79.4 → 49.8 wins of 100.
