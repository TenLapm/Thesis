Pathfinding: one weighted flood from the core

while (open.Count > 0) {
  SimNode c = open.Dequeue();
  int count = grid.GetNeighbors(c, nbrs);
  for (int k = 0; k < count; k++) {
    SimNode n = nbrs[k];
    if (!n.IsWalkable) continue;
    bool diag = n.X != c.X && n.Y != c.Y;
    int step = (diag ? 14 : 10) * n.TerrainCost;
    int cost = c.BestCost + step;
    if (cost < n.BestCost) { // ties keep first parent
      n.BestCost = cost;
      n.NextIndex = c.Index;
      open.Enqueue(n);
    }
  }
}

SPFA: queue-based shortest-path relaxation (Bellman, 1958; Moore, 1959), giving every tile a next step toward the goal (Emerson, 2019). Integer costs ×10, so no float enters the field. A rebuild resets every node first. Diagonals may not cut between two solid tiles.
