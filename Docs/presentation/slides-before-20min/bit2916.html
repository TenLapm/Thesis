One bit at tick 2916: why every float is cast

C# lets a runtime keep float intermediates at higher precision. .NET rounded after every operation. Unity’s Mono evaluated the whole chain in double and rounded once.

// before: runtimes disagree on rare steps
x + dx / d * step

// after: each cast forces a rounding, so every runtime gets the same bits
(float)(x + (float)((float)(dx / d) * step))
