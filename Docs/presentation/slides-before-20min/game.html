The game, as far as the code depends on it

Nothing blocks. A wall is expensive ground, not an obstacle. A path to the core always exists, so no placement ever needs a path check or a revert.

Map from a seed. 48 × 48 tiles, 22 rock ridges, up to 28 ore deposits, a 2-tile outer ring. Waves enter at 1 to 3 edge points.

Three levers, one resource (ore). Towers are damage, walls are time under fire, collectors are income away from the core.

Towers stand only on a wall or rock and fire only while powered.

Captured from Unity: wave 1, 27590234. Yellow marks are enemies on the route.
