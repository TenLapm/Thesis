Player study: within-subject, n ≈ 24

Design. Every player plays both versions, so each player’s own style cancels out. Pilot n = 5 first (G4).

Seeds. Two fixed seed sets, X and Y. No player meets a seed twice. Each condition gets each seed and position equally often.

Primary: placement entropy per session, Wilcoxon signed-rank (Wilcoxon, 1945), effect size dz (Lakens, 2013).

Also: fairness by non-inferiority (Walker & Nowacki, 2011) and an unprompted question on adaptation.
