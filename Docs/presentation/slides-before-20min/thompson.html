alpha[bin,a] = 1f + G*(alpha[bin,a]-1f) + r;
beta [bin,a] = 1f + G*(beta [bin,a]-1f) + (1-r);

Bernoulli keeps the update conjugate for rewards in [0, 1]. Decay toward Beta(1, 1), not zero, keeps α, β ≥ 1, so the Gamma sampler (Marsaglia & Tsang, 2000) needs no boost branch. Discount: the player changes too (Garivier & Moulines, 2011).
