Why one field and not A* per enemy

38 × 38 board, 10% wallsTime
One flow field, any number of enemies0.14 ms
A* for 500 enemies18.2 ms
A* for 1,000 enemies32.1 ms

One rebuild answers every enemy, from every tile, and is only needed when the map changes.

Removed on purpose: chunking, background threads, path validation, sinkhole detection. At this cost they only added bugs.

Rebuild time grows gently with board size: 4.2 ms at 100 × 100, 25% built.
