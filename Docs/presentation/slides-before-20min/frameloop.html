Why the rules left Unity’s frame loop

The original prototype

Movement used Time.deltaTime: results changed with frame rate and game speed.

Agents acted in Unity’s Update order, which Unity does not define.

Spawns used WaitForSeconds, so they snapped to frames.

State lived on scene objects: no test without a scene.
