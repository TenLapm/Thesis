1. Introduction

Dynamic Scripting (Spronck et al., 2006)

Nearest neighbour. Each agent class has a rulebase of hand-written rules, each with a weight.

Before a fight: rules are drawn into a script, with probability linear in weight.

After a fight: rules that ran gain or lose weight by fitness.

F < b: ΔW = −Pmax × (b − F) / b
F ≥ b: ΔW = +Rmax × (F − b) / (1 − b)

Results: ahead of static tactics after 13 to 53 fights on average.

How this project differs: it picks one strategy per wave, not the rules of each opponent. It keeps a separate estimate for each type of build, where Dynamic Scripting has no player context. It learns from how much the build changed, not from winning.

The gap: they argue it could “force the human player to seek continuously new tactics” (p. 226), but test that only against scripts. This project measures it on people.
