What’s next

1. Continue the gameplay design. More tester rounds until the game is worth studying. Each round is checked against its telemetry.

2. Build the systems still missing. The learner, the build profile, the strategies and cost table, the layered director, then the offline ladder and gates G1 to G3.

3. Run the study. Pilot with 5 players, freeze the thresholds, balance pass, freeze the build, then about 24 players.

To settle before the pilot: the static version sends one walker stream while the game’s normal waves are squads, and raids change the player’s income. Both can bias the comparison.
