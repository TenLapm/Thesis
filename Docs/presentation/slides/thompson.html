2. Methodology

Learning: Thompson sampling, bounded to ±1

Draw once from each cell’s curve (Thompson, 1933). A strategy it is unsure about sometimes draws high, so it explores with no ε to tune (Russo et al., 2018).

foreach (var a in surviving) {
  float theta = SampleBeta(alpha[bin,a], beta[bin,a]);
  float corr = IsCold(a) ? 0f : 2f*(theta-0.5f);
  score[a] = Heuristic(a, profile) + corr;
}
Play(ArgMax(score));

int r = Bernoulli(reward);
alpha[bin,a] = 1f + G*(alpha[bin,a]-1f) + r;
beta [bin,a] = 1f + G*(beta [bin,a]-1f) + (1-r);
// G = 0.95

Bernoulli keeps the update conjugate for rewards in [0, 1]. Decay toward Beta(1, 1), not zero, keeps α, β ≥ 1, so the Gamma sampler (Marsaglia & Tsang, 2000) needs no boost branch. Discount: the player changes too (Garivier & Moulines, 2011).
