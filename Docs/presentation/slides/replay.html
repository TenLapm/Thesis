2. Methodology

Supporting system: replay proves it is the same game

A replay stores inputs, not outcomes. To check one, run the rules again and compare a 64-bit FNV-1a hash of the state on every tick (Noll et al., 2026).

Result today: a session played in Unity and replayed under .NET 9 matched 14,807 of 14,807 tick hashes, and its telemetry came back byte for byte.

Not yet proven: a session recorded by a built player. That must be checked before the pilot.
