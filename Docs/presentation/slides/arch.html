2. Methodology

Supporting system: rules with no Unity in them

Arrows are the assembly references in the repository. Dashed box: empty today.

Headless: a 25-wave game takes 176 ms without Unity, so the learner can be tested offline.

Fixed ticks of 0.02 s, so frame rate never reaches the rules.

Own random numbers: PCG32 (O’Neill, 2014), one stream per subsystem.

Own maths, and a cast on every float step: one missing rounding split Mono from .NET by one bit at tick 2916.
