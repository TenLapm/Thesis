What is in the game right now

Board: a 48 × 48 map generated from a seed, and the player places the core.

Economy: one resource, ore, from collectors on deposits that run dry.

Build menu: 3 wall tiers, 8 towers and a pylon, upgrades, gear, research.

Enemies: 11 types in squads, from 1 to 3 entry points.

Every session leaves a replay and telemetry.
