2. Methodology

Reward: behaviour change, credited backwards

r = 0.45·restructure + 0.25·survived + 0.20·pressure + 0.10·novelty

Restructure: how much the build changed. This is the behaviour the thesis wants.

Survived: a defeated player builds nothing more, so ending the run must not pay.

Pressure: the share of the wave that came close to the core. A wave nobody feels asks no question.

Novelty: distance from the last wave, so the same wave is not sent again.

Timing: the reward for wave N is known only when wave N+1 is planned, and credit goes back to earlier waves at half weight per wave.

Design, not yet code. The game already records pressure, and telemetry has a reward field waiting.
