2. Methodology

Supporting system: planner interface and telemetry

One interface. Every study condition is one planner, so swapping one changes nothing else.

Failure contained. A planner that fails is replaced for that wave, and the session goes on.

Telemetry: one row per wave, made from the rules alone, so it can be rebuilt from the replay. The director’s fields wait there, empty for now.

public interface IWavePlanner {
  string Name { get; }
  WavePlan PlanWave(WaveContext context); // may only read context.State
  void OnWaveResolved(WaveOutcome outcome);
}
