1. Introduction

What this project is

A maze tower defense where nothing blocks the path. A wall is expensive ground that enemies can dig through.

An adaptive wave director. Before each wave, it reads the player’s build and picks the kind of attack to send.

A controlled study. The same game with and without the director, with difficulty held equal, played by real people.

A deterministic core. The rules are plain C#, and Unity is only a host, so every session replays exactly.
